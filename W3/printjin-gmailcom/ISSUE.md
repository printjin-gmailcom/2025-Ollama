## 🐛 Bug Report

### ⚠️ 문제 설명  
특정 페이지에서 버튼 클릭이 작동하지 않습니다. 아무런 반응이 없습니다.

### 🔁 재현 방법  
1. 홈페이지에 접속합니다.  
2. 문제의 버튼(예: "제출하기")을 클릭합니다.  
3. 아무 동작 없이 정지되어 있는 상태를 확인합니다.

### 🖼️ 스크린샷  
> 오류 화면을 캡처해 첨부해주세요.  
(예: `./assets/bug-button-error.png`)

### 🧩 예상 원인 및 해결 방향  
- JavaScript의 클릭 이벤트가 제대로 바인딩되지 않았을 가능성이 있음  
- DOM 로딩 이전에 스크립트가 실행되었는지 확인 필요  
- `addEventListener`를 `DOMContentLoaded` 이후에 설정하거나, `defer` 속성 추가 고려
